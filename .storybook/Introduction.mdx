## Two toolbars you'll use a lot

- **Theme** (top-right, mirror icon) — flips every story between **Dark**
  and **Light**. Uses the app's `ThemeProvider` so what you see is exactly
  what a user sees. No "dark variant" stories — P5 says one toolbar, never
  two copies.
- **Background** (top-right, photo icon) — paints the story canvas with
  `Background`, `Card`, `Muted`, or `Accent`. Use `Card` when you're
  showing a card-shaped atom so the contrast is real, not synthesized.

## Three panels you'll touch

- **Controls** — every prop shows up here with the right input type: select
  for enums, range slider for numbers, checkbox for booleans. Edit a value
  and the story re-renders.
- **Actions** — click handlers light up here. Stories wire them with
  `handlers(['onClick', ...])` from `.storybook/story-helpers.tsx`.
- **A11y** — Storybook's accessibility panel runs the same audits WCAG
  uses. Yellow/Red badges are bugs, not suggestions.

## Three rules every atom follows

1. **Tokens only.** No raw hex / rgb / oklch in components — every colour
   resolves through `var(--token)`. Edit a token in `src/App.css` and the
   whole app follows.
2. **Compound, not monolithic.** Each compound component (Card, Dialog,
   DropdownMenu, …) exports subcomponents and the story file shows every
   subcomponent as a labeled Slot.
3. **One canvas, one theme.** Use the Theme toolbar; never ship a
   `*-dark.tsx` story file.

## The gates that keep this true

Two commands, both inside `make check`:

- `npm run storybook-lint` — reads `docs/storybook-taxonomy.json` and checks
  every story file's title, story count, description, `autodocs` tag,
  explicit `layout`, `argTypes`, and token-only colours. No per-file
  allowlists: a story added today is graded today.
- `npm run storybook-render` — mounts every story in a real Chromium at
  **dark and light** and fails on a thrown play function, an empty canvas,
  or horizontal overflow. It exists because Progress once shipped three
  stories that rendered as a black rectangle and every text-based check
  passed.
