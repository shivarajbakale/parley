# App Shell

The rocketship shell has three layers, composed in [`src/App.tsx`](../src/App.tsx):

```tsx
<AuthGuard>
  <Titlebar title={pageTitleFor(pathname)} />
  <SidebarProvider>
    <AppSidebar />
    <SidebarInset>
      <Topbar />
      <main>
        <Outlet />
      </main>
    </SidebarInset>
    <CommandPalette />
  </SidebarProvider>
  <Toaster />
</AuthGuard>
```

The shell is a **fixed viewport** — `h-svh` with `overflow-hidden` all the way
down. Nothing here scrolls; pages scroll internally through `PageShell`, which
keeps headers and toolbars pinned. In a desktop window that rule carries more
weight than on the web: a window that scrolls as a whole reads as a web page in
a box.

`Titlebar` is the desktop-only layer — a frameless drag region that reserves
macOS traffic-light space and renders `null` in a browser. Anything interactive
inside it must opt out of dragging with `app-region-no-drag`.

## Routes

Public routes (`/login`, `/signup`) skip the chrome entirely — they render
the AuthLayout (split-pane brand panel + form). Everything else mounts inside
the authenticated chrome.
